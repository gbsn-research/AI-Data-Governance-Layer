# Conformance claim policy

An implementation claim must identify:

- ADGL specification version;
- implemented profile or subset;
- serialization, if relevant;
- conformance fixture version;
- normative checks executed;
- candidate or experimental checks executed separately;
- implementation version and immutable source identifier;
- known unsupported semantics;
- whether results were producer-authored, independently reproduced, or independently implemented.

Passing C01-C25 supports the claim:

> Passes the published ADGL 0.3 reference conformance fixtures C01-C25 for the declared implemented subset.

Passing C26-C36 additionally supports:

> Passes ADGL Toolkit 0.5.3 candidate execution-integrity fixtures C26-C36; these are not normative Specification 0.3.0 requirements.

The following claims are not supported by the current artifacts:

- independently certified ADGL implementation;
- complete cross-vendor interoperability;
- legal or regulatory compliance;
- production security assurance;
- conformance of an undisclosed proprietary extension;
- equivalence of all Analysis or Consequence Governance profiles.
