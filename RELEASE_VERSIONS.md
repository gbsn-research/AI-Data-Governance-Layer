# Release Versions

- ADGL Research Release: **0.4.0**
- Public Distribution Package: **0.4.3**
- Main paper: **v0.9**
- Semantic specification: **0.3.0**
- Paper-evaluated Reference Toolkit: **0.5.0**
- Current Public Reference Toolkit: **0.5.3**

The v0.9 research paper and Appendix D report the Toolkit 0.5.0 evaluation baseline. Toolkit 0.5.3 preserves that historical result while adding post-paper candidate execution-integrity hardening discovered through implementation testing. Those candidate semantics are not represented as already normative in Specification 0.3.0.

The research release is an umbrella bundle. Individual artifacts use independent versions because paper, specification, implementation, and public-distribution maturity do not advance at the same rate.
