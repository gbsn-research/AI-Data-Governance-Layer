# Release Versions

- ADGL Public Research Release: **0.4.4 (Release 2)**
- Main paper: **v1.2 submission master**
- Semantic specification: **0.3.0**
- Paper-evaluated Reference Toolkit: **0.5.0**
- Current Public Reference Toolkit: **0.5.3**

The v1.2 paper reports the Toolkit 0.5.0 evaluation baseline and separately discusses Toolkit 0.5.3. Toolkit 0.5.3 preserves the 25 published normative checks while adding 11 candidate execution-integrity checks discovered through implementation testing. Those candidate semantics are not represented as already normative in Specification 0.3.0.

The research release is an umbrella bundle. Individual artifacts use independent versions because paper, specification, implementation, and public-distribution maturity do not advance at the same rate.
