# ADGL Profiles

A `Profile` is a named, versioned collection of ADGL policy semantics, control mappings, conformance fixtures and optional implementation guidance for a defined domain or purpose.

The repository includes **illustrative, non-normative** examples under `profiles/illustrative/`:

- Sovereign Processing Profile
- Life Sciences Evidence Profile
- Financial AI Controls Profile
- Agent Least-Privilege Profile
- Regulatory Control Mapping Profile

These examples demonstrate extensibility. They are not legal advice, do not establish regulatory compliance, and are not normative parts of ADGL 0.3.
