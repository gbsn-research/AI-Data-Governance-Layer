# Contributing

This repository is intended for standards-oriented experimentation.

For semantic changes:
1. Open an issue describing the problem.
2. State whether the change affects normative paper semantics or an experimental extension.
3. Provide at least one executable conformance case.
4. Document compatibility implications.
5. Do not redefine an existing operation without a versioned proposal.

Questions about ADGL specification development may be sent to
`aidatagovernance@gbsnresearch.com`. Normative changes should normally use
the public specification-change issue template so discussion and disposition
remain visible.
