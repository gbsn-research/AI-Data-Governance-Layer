# ADGL Specification

The human-readable working specification is split into two primary documents:

1. `ADGL_Core_Semantic_Specification_0.3.0.md` — primitive objects, relationships, policy semantics, states, profiles,
   extensions, audit minimums, and base conformance.
2. `ADGL_Governance_Stages_and_Outcome_Model_v0.9.md` — Knowledge Governance, Analysis Governance, Consequence
   Governance, `INFORM / DECIDE / ACT`, audit/provenance, and feedback/derived-knowledge behavior.

Machine-readable schemas live in `/schemas`.

The YAML examples are a reference serialization. ADGL conformance is intended to attach to observable semantics rather
than a particular syntax or implementation language.
