# Security Policy

This repository is an experimental reference implementation. Do not deploy it as a production security boundary without independent review and hardening.

## Reporting a vulnerability

Please **do not open a public issue for an undisclosed security vulnerability**.

Go to **www.gbsnresearch.com** and use **Contacts** to reach GBSN Research privately. Include the repository/version, a concise description, reproduction information where appropriate, and any potential impact.

GitHub Private Vulnerability Reporting should also be enabled on the public repository when available.
