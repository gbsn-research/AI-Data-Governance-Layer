# ADGL Public Research Release 0.4.4 — Release 2

Release 2 synchronizes the academic paper, companion appendices, public toolkit documentation, disclosure language, and project governance without changing the normative Core Specification 0.3.0.

## Included

- Main Paper v1.2 submission master.
- Revised companion Appendices A-E in Markdown, DOCX, and PDF.
- Reference Toolkit 0.5.3.
- Eight constructed executable reference cases.
- 25 published normative checks and 11 candidate execution-integrity checks.
- Apache-2.0 reference software and CC-BY-4.0 specification/documentation.
- Commercial-interest, implementation-boundary, conformance-claim, and maintainer-governance disclosures.

## Evidence and disclosure changes

- All eight cases are identified as constructed fixtures rather than empirical case studies.
- Public conformance is described as producer-authored internal consistency evidence.
- KEE is disclosed as a separate unpublished proprietary commercial MVP developed by GBSN Research.
- KEE development findings are used as formative design-science evidence and traced to candidate checks C26-C36.
- KEE is not required for ADGL implementation, is not public reproducibility evidence, and does not define normative conformance.
- No independent or clean-room implementation has yet been validated.
- Portability, interoperability, governance effectiveness, and standards readiness remain bounded claims and research objectives.

## Reproduced package checks

- 20/20 public software tests passed.
- 25/25 published normative checks passed.
- 11/11 candidate checks passed.
- 36/36 total current checks passed.

These results confirm packaged execution; they are not independent semantic certification.

## C15 terminology

The displayed C15 label is now `portable-subset interpreter equivalence`. Its fixture behavior is unchanged. The bundled mini-interpreter is producer-authored and does not demonstrate third-party interoperability.
