# ADGL Research Roadmap

## Near term

1. Harden cross-stage execution-integrity semantics.
2. Formalize Analysis Preflight / analytical execution / Analysis Postflight.
3. Strengthen AnalysisResult output contracts and confidence provenance.
4. Formalize trusted governance assertions and capability-grant lifecycle.
5. Strengthen audit causal ordering and effective-decision consistency.
6. Add independent implementation/back-end conformance evidence.

## Research validation

- independent runtime or policy-engine implementation;
- real `DECIDE` human-decision workflow;
- real `ACT` tool/API integration;
- cross-provider reasoning experiments while holding governance semantics constant;
- expanded conformance suite.

## Standards objective

Develop ADGL as an implementation-neutral semantic and conformance layer rather than a requirement to use this
reference implementation.
