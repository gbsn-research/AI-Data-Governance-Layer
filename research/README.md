# Research Paper

This directory contains the ADGL research paper and its companion appendices in both Markdown and original DOCX form.

The paper package is organized as:

- Main Paper
- Appendix A — Core Semantic Specification
- Appendix B — Governance Stages and Outcome Model
- Appendix C — Reference Use Cases and Illustrative Profiles
- Appendix D — Reference Toolkit, Conformance, and Evaluation
- Appendix E — Comparative Analysis

The Markdown exports are provided for repository browsing. The DOCX files preserve the publication-layout source.
